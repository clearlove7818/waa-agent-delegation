# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credential exposure, permission bypasses, or unsafe installation behavior in a public issue.

Use GitHub's private vulnerability reporting or Security Advisory interface for this repository. Include the affected version or commit, reproduction steps, impact, and any known mitigation. If private reporting is unavailable, open a minimal public issue requesting a private contact channel without including sensitive details.

Ordinary Skill behavior defects that do not expose sensitive information or bypass authority may be reported through public issues.

## Scope

Security reports may cover repository content, installation guidance, permission-boundary errors, or behavior that could cause a delegated executor to exceed the primary task's authority. The Skill text itself cannot grant filesystem, network, tool, sandbox, platform, or external-action permissions.
